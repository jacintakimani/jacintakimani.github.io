02
Automation · Proof of concept
Playwright + TypeScript

Browser automation with plain-English run reports

A manual routine (log in to a portal, find files, download them, record what happened) took staff time every week. I built a proof of concept that does the whole routine automatically. I tested it on my own GitHub repository because GitHub uses the same login pattern as the real portals (username, password and authenticator-app MFA), and those portals had no APIs to use instead.

I built three versions, each suited to a different level of risk:

  • Attended: a person logs in and approves MFA, then the automation takes over and reuses the saved session
  • Fully automated: on a test account, the MFA code is generated automatically from a secret held in AWS Secrets Manager, never in the code
  • Supplier portal: built for a real, lower-risk portal but deliberately not run live, because there was no safe test environment

Each version was built to:

  • Download and extract files to a set folder on the computer
  • Generate a self-contained HTML report in plain English, with guidance if a step fails
  • Run with one click from a desktop shortcut, so non-technical staff can use it
  • Mask credentials in reports and traces for security

05
Data science · University project
Master of Data Science, UniSA · 2023

Retail sales forecasting: what drives weekly sales?

Using Walmart's public sales data for 45 stores across three store types, the project asked which factors drive weekly sales and how accurately they can be forecast, to support inventory and staffing decisions.

  • Explored sales by store type, store, department and season, alongside holidays, temperature, fuel price, CPI and unemployment
  • Found store size was the strongest driver of sales. Large stores saw clear peaks from October to January, and sales dipped when unemployment rose above 10% or temperatures were extreme
  • Compared three approaches for each store type: linear regression (tuned with GridSearchCV), SARIMAX time-series forecasting, and random forest regression
  • Random forest performed best, with R² of at least 0.86 for every store type and up to 0.98. The SARIMAX model explained about 80% of the variation in overall sales
  • Assessed every model with MAE, MSE, R², and residual and QQ plots, and noted where each one was unreliable, such as on outlier weeks
